数据来自 Linux 命令 vmstat 1，每秒刷新一次。每组图表下方列出各指标的缩写、中文含义、当前数值和说明。 鼠标悬停在指标上可看到 vmstat 官方英文解释。

怎么判断服务器是否健康？

  • CPU 繁忙：“空闲 id” 长期低于 20%，或 “运行队列 r” 长期大于 CPU 核数，说明 CPU 不够用。
  • 内存紧张：Linux 会尽量把空闲内存拿来做缓存，所以 “free” 小不代表内存不够。 真正该关心的是 “换入 si / 换出 so” 是否持续大于 0 —— 那说明物理内存已经不够、开始用硬盘顶替了。
  • 磁盘瓶颈：“IO 等待 wa” 持续偏高（比如 > 10%），或 “阻塞进程 b” 经常不为 0，说明程序在等磁盘。
  • 云主机被抢占：“被偷 st” 持续偏高，说明宿主机上的其它虚拟机在抢 CPU，属于云厂商侧的问题。
